<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model and sandbox text -> terminal | Rationales, diffs, and stage logs originate in a model or a sandbox |
| ledger file -> CLI | A hand-edited or damaged ledger is read |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-09-01 | Tampering / Spoofing | Terminal escape and bidi injection through a rationale, diff line, or stage log | high | mitigate | `LogExcerpt` for rationales and logs, `SafeText` for the diff and every line; tested with ESC and U+202E |
| T-08-09-02 | Information disclosure | A hostile stage log printed by default | medium | mitigate | Logs print only with `--logs` (D-17); tested |
| T-08-09-03 | Denial of service | A large blob exhausting memory or the terminal | medium | mitigate | Blobs read under `MAX_RATIONALE_BYTES`, `MAX_STAGE_LOG_BYTES`, and the diff caps; excerpts capped |
| T-08-09-04 | Repudiation | A corrupt ledger shown as healthy | medium | mitigate | `status` reports `Corrupt` with line and kind and exits unhealthy; tested |
| T-08-09-05 | Denial of service | `status`'s liveness probe blocking a starting driver | low | accept | The probe holds the lock for an instant; a driver that starts then gets `RunLocked`, which says to retry (08-RESEARCH Pitfall 7) |
</threat_model>

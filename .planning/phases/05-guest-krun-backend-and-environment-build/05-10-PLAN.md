## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| candidate -> /out | The candidate writes /out; root PID 1 packs it |
| diff -> source tree | A model-produced diff is applied inside the guest only |
| judge VM inputs | Judge data and candidate output enter only a judge-role job |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-10-01 | Information disclosure | A symlink or hard link in /out making root PID 1 pack a root-only file (judge data in a judge VM) | high | mitigate | Kill-all before packing (StageExecutor contract); symlink_metadata, O_NOFOLLOW open, device and inode match, one-link regular files only; anything else is Invalid with no out/ entries |
| T-05-10-02 | Spoofing | A candidate placing a scorecard in its output | high | mitigate | Only a Judge-role status adds .minos/scorecard.json; a candidate's /out/scorecard.json is packed as out/scorecard.json; the host's into_scorecard exists only on judge output |
| T-05-10-03 | Tampering | Diff applied with fuzz or offset search | high | mitigate | Diff::parse against the writable set, ExperimentId binding check, the core strict applier; mismatch is ApplyStatus::Failed and no stage runs |
| T-05-10-04 | Elevation of privilege | Archive entries escaping the destination | medium | mitigate | RelPath names, regular files only, create_new, no setid modes; tar unpack methods banned by the guest clippy.toml, each ban proven |
| T-05-10-05 | Denial of service | Oversized output or logs | medium | mitigate | Core output caps, LOG_CAP_BYTES per log, scorecard cap |
</threat_model>

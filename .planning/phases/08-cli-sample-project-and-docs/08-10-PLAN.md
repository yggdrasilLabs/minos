<objective>
Implement the review gate's last two steps: `report`, which renders and hashes the review artifact, and `adopt`, which accepts only that exact hash, records the acknowledgment, and writes a canonical patch file that both standard tools apply.

Purpose: CLI-08 and CLI-09, and the third property Minos exists for: nothing the lab produces reaches the user's machine without a report they acknowledged. The patch is a file the user applies; Minos never applies it. COST-02 holds for both commands' output, the report text included.
Output: `report.rs`, `adopt.rs`, the report and adopt tests, and the patch golden test.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| lab output -> user's machine | The patch file is the only artifact that leaves the lab; the review gate guards it |
| model text -> terminal | Report text, rationales, and diff lines originate in a model |
| CLI -> filesystem | `adopt` creates one file in the user's project |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-10-01 | Tampering | Adopting a patch other than the one reviewed | high | mitigate | `adopt` rebuilds the report and compares the `ReportHash` byte for byte before any append or write; stale-report case tested |
| T-08-10-02 | Elevation of privilege | Bypassing the review gate | high | mitigate | No code path writes the patch before `ReportAcknowledged` is appended for that exact hash; tested in order |
| T-08-10-03 | Tampering | Overwriting a user file or following a symlink at the patch path | high | mitigate | `create_new(true)` (`O_EXCL`) for the default path and `--out`; tested |
| T-08-10-04 | Tampering | Applying changes to the working tree | high | mitigate | `adopt` writes only the patch file; it execs nothing; the module doc and output say Minos never applies a patch |
| T-08-10-05 | Tampering / Spoofing | Terminal injection through the report or diff | medium | mitigate | Every line through `write_line` (`SafeText`); the file keeps the canonical bytes so the hash stays true (D-12) |
| T-08-10-06 | Repudiation | A user believes a patch applied when `git apply` skipped it | medium | mitigate | Printed commands use `patch -p1` and `--directory`; the golden pins the silent no-op |
| T-08-10-07 | Repudiation (cost) | The report or `adopt` wording a figure as an estimate or as exact | low | mitigate | `assert_no_banned_words` runs over `Report::text()` and every captured output in `report_adopt.rs` |
</threat_model>

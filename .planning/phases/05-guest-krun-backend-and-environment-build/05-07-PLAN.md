<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| supervisor -> helper config | The host writes the config; the helper validates it as hostile |
| guest -> helper stderr | msb_krun device logs can carry guest-influenced bytes to the stderr the supervisor classifies |
| helper -> host | The entitled helper is the guest's neighbor on the host |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-07-01 | Tampering | Guest-influenced log text forging a watchdog marker (forces infinite infra retries) | high | mitigate | Logger prefixes every line with "minos-vmm: log ", replaces every non-printable character, caps the total; the supervisor matches markers as exact whole lines together with the exit code (05-15) |
| T-05-07-02 | Elevation of privilege | A writable or shared device reaching the guest | high | mitigate | Config v2 has no scratch disk and no boot mode; two read_only raw disks; clippy bans on virtio-fs, hijack, remap, format, custom console, and custom vsock backends, each proven to fire |
| T-05-07-03 | Denial of service | Helper writing large files or core dumps on the host | medium | mitigate | RLIMIT_FSIZE 0 (pipe) or cap + 64 KiB (file), RLIMIT_CORE 0, RLIMIT_NOFILE 1024, set before the config is read; failure exits 66 |

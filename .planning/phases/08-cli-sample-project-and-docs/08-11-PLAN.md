## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user -> running driver | `stop` is the only control a user has over a running session |
| CLI -> user files | `init` creates files in the project and in `~/.config/minos` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-11-01 | Denial of service | A stop that silently does nothing | medium | mitigate | `stop` refuses when no driver holds the run (D-13); each stop carries a fresh ordinal so a repeat is honored; tested with a live driver |
| T-08-11-02 | Denial of service | `stop` holding the driver lock and blocking the driver | medium | mitigate | The probe guard is dropped before the append; the append takes only the ledger lock |
| T-08-11-03 | Denial of service | Probing an unknown run creates a directory | low | mitigate | `stop` probes only a run `Ledger::runs` lists (Pitfall 8) |
| T-08-11-04 | Tampering | `init` overwriting a user's file or writing through a symlink | medium | mitigate | `symlink_metadata` pre-check and `create_new` (`O_EXCL`) for every file; tested |
| T-08-11-05 | Repudiation (cost) | A template that prices a run at zero | medium | mitigate | Non-zero compute rates; empty `[models]` makes model proposers refuse with `PricesMissing`; tested |
| T-08-11-06 | Information disclosure | A world-readable price file or directory | low | mitigate | Directories created 0700 and the file 0600 |
| T-08-11-07 | Repudiation | A stop recorded after the run ended is ignored by the next session | low | accept | Inherent to session-relative stops (07-CONTEXT D-19); `stop` prints that it has no effect then (Pitfall 7) |
| T-08-11-08 | Repudiation (cost) | A template or message wording cost as an estimate or as exact | low | mitigate | `assert_no_banned_words` runs over `stop`'s output, every file `init` writes, `PRICES_TEMPLATE`, and the error texts |

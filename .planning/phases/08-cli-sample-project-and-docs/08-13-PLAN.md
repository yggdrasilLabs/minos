<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| guest VMs -> host | Real candidate and judge VMs run the sample; their output crosses only through the runner |
| registry -> image build | `env build` pulls the digest-pinned base image |
| test variables -> tests | `MINOS_*` are read only by ignored tests |
| user's subscription -> live tests | Real model calls on the user's own login |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-13-01 | Information disclosure | The answer key reaching the candidate VM | high | mitigate | The end-to-end test runs the production runner, which attaches judge data only through `secrets`; the sample's snapshot excludes `judge/` (08-05 test) |
| T-08-13-02 | Repudiation | Claiming DOCS-02 or a measurement without a recorded run | medium | mitigate | 08-EVIDENCE.md records verbatim output and exit codes; a host refusal becomes a `checkpoint:human-action`, never a skipped record |
| T-08-13-03 | Elevation of privilege | Production code reading `MINOS_*` test variables | medium | mitigate | Only the ignored test reads them; 08-15's gate greps `crates/*/src` for them |
| T-08-13-SC | Tampering | The base image pulled during `env build` | high | mitigate | Pinned by index digest; `env build` refuses unpinned `FROM` lines and records the digests in `minos.lock`; no package-manager install runs |
| T-08-13-04 | Repudiation (cost) | Live model calls spending the user's subscription without consent | medium | mitigate | The live suite runs only at a `checkpoint:human-action`, by the user |
</threat_model>

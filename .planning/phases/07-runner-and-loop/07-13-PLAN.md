- `pub const RETRY_PAUSE: Duration = Duration::from_secs(5);` documented "the fixed pause before an infrastructure retry (D-16): long enough for a transient host fault to clear, short against a stage budget; tests pass zero" (used by 07-15). `#[derive(Debug, Clone, Copy)] pub struct DriverOptions { pub retry_pause: Duration }` with `Default` giving `RETRY_PAUSE`.
- `pub struct Calibration { trials: u32, floor: Option<NoiseFloor>, verdict: NoiseVerdict }` with accessors; `pub enum Calibrated { Ready(Calibration), Stopped { reason: StopReason } }` (07-15's safe points can end a session during generation 0); `#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum RunEnd { Reached { generation: u32 }, Stopped { generation: u32, reason: StopReason } }`.
- `pub struct Driver<'a, S, P, J, O> where S: Ledger + Blobs + RunLock, P: ModelProvider, J: JobRunner, O: Observer` holding `store: &'a S`, `guard: S::Guard<'a>` (held for the whole session; released on drop), `proposer: &'a Proposer<P>`, `jobs: &'a J`, `observer: O`, `inputs: RunInputs<'a>`, `options: DriverOptions`, `run: RunId`, and a session set of generations whose batch was completed. No other state: everything else is re-derived from the fold.
- `pub fn start(store, proposer, jobs, observer, inputs, options, started_at: u64) -> Result<Self, DriverError>`: `check_start`; `jobs.check(&baseline_request(0))` (a `JobFailure::Config` is `DriverError::Job`, infra is `DriverError::Infra` until 07-15) before anything is recorded; `RunId::of(&inputs.manifest_id(), &inputs.base.id(), started_at)`; `store.lock_run(&run)` (`StoreError::RunLocked` becomes `DriverError::RunLocked`); `put` the manifest bytes (their blob ID has the manifest ID's digest); append `RunStarted { .., root_image: Some(inputs.root_image) }` through `record::append`; fold; `check_resume` with the current manifest as the recorded one.
- `pub fn resume(store, proposer, jobs, observer, inputs, options, run: RunId) -> Result<Self, DriverError>`: lock first, then read and fold (no records is `RunNotFound`); fetch the recorded manifest blob (the `BlobId` parsed from `state.manifest()`'s hex, under the CLI's manifest cap; absent or unparsable means `None`) and parse it; `check_resume(&state, recorded.as_ref(), &inputs)`; on `Resume::ManifestChanged { from_generation }`, `put` the new manifest bytes and append `ManifestChanged { manifest: inputs.manifest_id(), from_generation }` (D-19); then `jobs.check`.
- `pub fn run_id(&self) -> RunId`, `pub fn observer(&self) -> &O`, `pub fn into_observer(self) -> O`.
- A private `fn state(&self) -> Result<RunState, DriverError>` that reads and folds the ledger (refolded before every step; never cached).
- `pub fn calibrate(&mut self) -> Result<Calibrated, DriverError>`: loop on `next_step(&state, &judge, trials, CANDIDATE_TRIALS, 0)`; each `Calibrate { trial }` builds `JobRequest::baseline(base, judge, trial, JobBudget::from_budget(..))`, calls `jobs.run`, then records `spend_once(Candidate { baseline, trial })`, `spend_once(Judge { .. })` when the result has a judge usage, and `Judged { exp, judge, trial, outcome, backend, logs }` (`logs` is `Some` when the result names any log, else `None`), and emits `LoopEvent::Calibrated`; at `Done`, refuse with `BaselineUnscored { trials }` unless `baseline_ready`, then return `Calibrated::Ready` with the noise floor of the first objective's metric and `noise_check` against that objective.
- `pub fn run_to(&mut self, target: u32) -> Result<RunEnd, DriverError>`: `calibrate()` first (a `Calibrated::Stopped` returns `RunEnd::Stopped { generation: 0, .. }`), then loop on `next_step(.., target)`:
  - `Propose { g }`: `parent_tree`, `route` with `SurfaceStats` of the base tree's total bytes, the routed `ProposerSpec` (an index the manifest lacks is `DriverError::Route`), `history`, `notes`, `call = state.next_model_call(g)`, `proposer.propose(spec, &ProposeInput { .. })`. On `Err(e)`: `spend_once(ModelCall { call, model })` when `e.usage()` is some (model: the spec's model); a `stop_reason()` appends `StopRequested { g, reason }`, emits `Stopped`, and returns `RunEnd::Stopped`; `is_infra()` is `DriverError::Infra { what: "the model provider" }` (07-15 retries it); otherwise `DriverError::Propose(e)`. On `Ok(p)`: `spend_once` per `p.models()` entry under `call`, or once from `p.usage()` under the spec's model when `models` is empty (a sweep has neither); then `admit(..)`; with no batch, conclude now with the admission's drop count; with a batch, append every `missing_proposed` event and emit `LoopEvent::Proposed`.
  - `RunTrial { g, exp, trial }`: complete the generation's batch once per session (`load_batch`, then append `missing_proposed`), `recorded_diff`, `Experiment::candidate(cumulative)`, `JobRequest::candidate(&experiment, proposal.diff(), judge, trial, budget)`, `jobs.run` (`Config` is `DriverError::Job`; `Infra` is `DriverError::Infra` until 07-15), then the same two `spend_once` calls and `Judged`, and `LoopEvent::Judged` with the reduced objective delta (the experiment's lower-median objective under `TrialRule::AllScored` minus the incumbent's under `ScoredOnly`, through `Metric::new`, `None` when either is missing).
  - `Conclude { g }`: complete the batch, take `dropped` from it (0 when the generation has no batch), `conclude(&state, manifest, &judge, g, dropped)` (`DriverError::Policy` on error), append `Selected`, emit `LoopEvent::Selected`.
  - `Done { generation }` returns `RunEnd::Reached { generation }`; a `Calibrate { trial }` step (reachable only if calibration did not finish) runs that baseline trial through the same private helper `calibrate` uses.
- Module docs: record before act, the fold as the only state, the absolute target, what `calibrate` is for (D-06), and the Phase 8 interface points.
`lib.rs`: `pub mod driver;` and re-exports of `Driver`, `DriverOptions`, `RunEnd`, `Calibration`, `Calibrated`, `RETRY_PAUSE`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model output (via minos-propose) -> ledger | Only validated proposals with minted cumulative diffs are admitted |
| job runner -> ledger | Results cross with host-measured usage and blame; the loop records them before the next act |
| ledger -> driver on resume | The fold is the only state; resume re-derives the step |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-13-01 | Repudiation | Acting before recording, so a crash loses an effect | high | mitigate | Each `Spent` precedes its `Proposed` or `Judged`; the batch blob precedes the first `Proposed`; `Selected` follows the last `Judged`; tests assert seq order (D-07, D-18) |
| T-07-13-02 | Tampering | Driving a run with two processes | high | mitigate | `start` and `resume` take `RunLock` before any read or append and hold the guard for the session (LOOP-06; exhaustive tests in 07-16) |
| T-07-13-03 | Denial of service (billing) | Paying for model calls on a run whose baseline cannot score | medium | mitigate | `calibrate` ends with `baseline_ready`; `BaselineUnscored` stops before any propose (Pitfall 12) |
| T-07-13-04 | Denial of service (billing) | Retrying a provider limit or auth refusal | high | mitigate | A provider stop appends `StopRequested` and ends the session; never retried (06 D-13, D-15) |
| T-07-13-05 | Tampering | A rebuilt image, a changed manifest, or unpriced models at start | high | mitigate | `check_start` and `check_resume` run before anything is recorded; tests assert no ledger line on refusal (D-10, D-13) |
| T-07-13-06 | Repudiation | Continuing past a conflicting append | high | mitigate | `DriverError::Conflict` stops the driver naming run, seq, and kind; a test injects one and asserts nothing follows (D-08) |
</threat_model>

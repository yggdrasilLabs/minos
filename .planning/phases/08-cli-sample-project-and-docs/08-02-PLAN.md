<objective>
Give the `Ledger` trait a way to list its runs, so `minos check` can find a calibrated diagnostic run (D-05) and every run-taking command can resolve a hex prefix or default to the latest run (D-10).

Purpose: No store method lists runs today (08-RESEARCH G2). It must be a trait method, not a `FileStore` extra, so the later DynamoDB store implements the same contract, and it must never treat a directory left by a lock probe as a run.
Output: `Ledger::runs` on both stores, with contract tests.
</objective>

    - A run that was locked with `lock_run` and released, with nothing appended, is not listed
    - A `FileStore` whose `runs/` holds a symlink, a regular file, or a directory not named by 64 lowercase hex returns `Err(StoreError::Unsafe { .. })` from `runs()`
    - A `FileStore` whose `.minos/runs` directory does not exist yet lists no runs and creates nothing

  <action>
1. lib.rs: add to `Ledger` a required method `fn runs(&self) -> Result<BTreeSet<RunId>, StoreError>` with docs: every run with at least one appended line, in `RunId` order; a run that was only locked is not a run; `# Errors` naming `Io`, `Unsafe`, and `Poisoned`. Use `BTreeSet` (ordered output, CLAUDE.md "Order must be stable").
2. memory.rs: implement it as the key set of runs whose ledger holds at least one line, taking the same lock `read` takes and mapping a poisoned lock to `StoreError::Poisoned`.
3. file/ledger.rs: implement it for `FileStore`. If `runs_dir()` does not exist (checked through the existing `dir_exists`, which refuses a symlink), return an empty set and create nothing. Otherwise read the directory; for each entry use `symlink_metadata`: a symlink, a non-directory, or a name that is not valid UTF-8 or does not parse as `RunId` (64 lowercase hex) is `StoreError::Unsafe { what: "run directory" }`; a valid run directory is listed only when its `ledger.jsonl` exists as a regular file (checked with `symlink_metadata`; a symlinked ledger is `Unsafe { what: "ledger" }`). Directory read failures are `StoreError::Io` with a fixed `op` text. No file is opened for writing and no directory is created.
4. contract.rs: add generic cases `runs_lists_appended_runs<L: Ledger>`, `runs_of_an_empty_store_is_empty<L: Ledger>`, and `a_locked_run_is_not_listed<S: Ledger + RunLock>` and register them in the existing macros for both stores. Add file-only tests: a symlink under `runs/`, a regular file under `runs/`, and a directory named `not-a-run` each make `runs()` return `Unsafe`; a `FileStore` opened on a fresh directory lists nothing. Arrange-act-assert with `TestResult`; no unwrap, expect, indexing, or allow.
5. The two test-only `Ledger` implementors in minos-loop gain `fn runs(&self)` forwarding to their inner store (`Counting` in tests/blocks.rs, `FaultStore<S>` in tests/driver/support.rs), unchanged in every other respect, so `cargo test -p minos-loop` still compiles and passes.

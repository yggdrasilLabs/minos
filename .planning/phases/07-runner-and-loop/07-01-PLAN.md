## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ledger file -> fold | Ledger lines are parsed by `Record` with `deny_unknown_fields`; a resumed run trusts only what the fold derives |
| runner -> ledger (via loop) | Log blob IDs and judge usage enter the ledger as IDs and integers only; no sandbox bytes are inline |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-07-01-02 | Tampering | Unknown or malformed keys in a ledger line | medium | mitigate | `deny_unknown_fields` stays on every variant; a bad `Stage` map key is refused (closed enum); tests cover both |

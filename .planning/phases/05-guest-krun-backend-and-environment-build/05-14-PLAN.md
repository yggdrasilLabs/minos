## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user shell -> minos | The CLI runs with the user's environment; host tools inherit only what it passes |
| host tools -> terminal | codesign, docker, ps output is printed to the user |
| store -> backend | FileBlobSource hands bytes and paths from .minos to the backend |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-14-01 | Tampering | Packing the wrong guest binary (the macOS build) as /init | medium | mitigate | locate accepts a guest only after check_guest_elf; the rejected candidate is listed with its reason |
| T-05-14-02 | Elevation of privilege | Signing with extra entitlements | medium | mitigate | setup embeds the committed plist (test asserts byte equality) and verifies both keys after signing |
| T-05-14-03 | Spoofing | Environment variables redirecting binary or kernel lookup | medium | mitigate | locate reads no environment variable and no config file (D-04); MINOS_* are read only by ignored tests |
| T-05-14-04 | Information disclosure | Terminal escapes in tool output | low | mitigate | Every tool string passes through SafeText before printing |
| T-05-14-05 | Tampering | A blob path that is a symlink | medium | mitigate | FileBlobSource uses FileStore::verified_path (symlink and inode checks) and VerifiedPath::new |
</threat_model>

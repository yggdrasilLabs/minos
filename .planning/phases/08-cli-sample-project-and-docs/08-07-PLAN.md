<objective>
Implement `minos check` as a library function: validate and report the project's facts, report the provider preflight, and calibrate the baseline on a reused or fresh diagnostic run, printing the noise floor beside `min_improvement`.

Purpose: CLI-05 and JUDGE-02. `check` is where a user learns, before spending on a model, whether the manifest, image, judge, budget, and noise floor make sense. Everything it prints comes from core functions (`route_table`, `candidate_allowance_mib`, `judge_scratch_needed_bytes`, `noise_floor`, `noise_check`); the module is layout and composition.
Output: `check.rs` and its integration tests.
</objective>

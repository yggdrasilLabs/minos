## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backend -> helper | The backend's argv and config decide what the confined helper may touch |
| user Dockerfile -> root image | The packer writes /init and mount points after every user file |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-09-01 | Tampering | A modified profile file on disk weakening confinement | high | mitigate | The profile is compiled into the backend with include_str!, passed with -p, and its SHA-256 pinned by a test |
| T-05-09-02 | Elevation of privilege | A profile parameter left unset or a relative path widening a rule | high | mitigate | ProfileParams refuses relative paths; a test proves the profile's params equal the argv's -D names; the only network rule names SOCK |
| T-05-09-03 | Repudiation | A wrong guest binary packed as /init, blamed on the candidate | medium | mitigate | check_guest_elf refuses non-ELF, non-AArch64, non-64-bit, big-endian, and dynamic binaries; callers run it before packing or recording guest_sha256 |
| T-05-09-04 | Tampering | Drift between the helper's parser and the backend's serializer | medium | mitigate | Serializer test compares with the golden file byte for byte and pins its SHA-256 |
| T-05-09-05 | Repudiation | Losing the spike evidence with the harness | low | accept | Evidence stays verbatim in 02-SPIKE-EVIDENCE.md and 05-EVIDENCE.md; the SUMMARY maps each removed test to its successor |
</threat_model>

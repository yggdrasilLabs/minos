<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| candidate -> network | Any guest path to the host or the internet |
| host environment -> guest | Host values that could leak into the guest |
| launcher process -> helper lifetime | A dead launcher must not leave a VM |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-19-01 | Information disclosure / Elevation | Guest egress through TSI or a network device | high | mitigate | exit_egress fails closed on any connect, checks host canaries, the interface list, and the virtio device list |
| T-05-19-02 | Information disclosure | Host environment or identity in the guest | high | mitigate | exit_env with a random canary, the host HOME and USER, exact env keys, exact cmdline tokens |
| T-05-19-03 | Denial of service | VMs surviving kill -9 of the launcher | high | mitigate | exit_kill9 asserts the helper exits within 5 s, no process names the job, and the sweep removes the job dir |
| T-05-19-04 | Spoofing | Candidate forging the output stream or reading the token | high | mitigate | exit_forge asserts ChunkProtocol and that /dev/vdb is unreadable to the candidate |
| T-05-19-05 | Repudiation | An accepted host-derived boot token | low | accept | KRUN_BOOT_START_NS is the only allowed host token, all digits, recorded and flagged for the user |
</threat_model>

<objective>
Implement the file-backed store: the append-only, locked, durable JSONL ledger with torn-tail tolerance, and the content-addressed, atomically written, verified blob tree; then run the shared contract against it.

Purpose: STORE-02 (append-only JSONL under an exclusive lock, torn final line tolerated, unknown `v` refused, never rewritten), STORE-03 (same-key append is a no-op), STORE-04 (SHA-256 content address, temp-then-rename, verified read), and STORE-01 parity with the memory store. This is the crash-safety half of the Phase 4 goal ("run history survives crashes").
Output: file/mod.rs, file/ledger.rs, file/blobs.rs, the file arms in tests/contract.rs, tests/file_ledger.rs, tests/file_blobs.rs.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| disk -> store reads | Ledger lines and blob bytes on disk may be torn by a crash, edited, or replaced; every read validates them |
| concurrent processes -> one ledger | run, steer, and stop may append at once |
| project tree -> store root | A cloned project may already contain a .minos path, possibly a symlink |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-05-01 | Tampering | Ledger record rewritten or history truncated | high | mitigate | Append-only open, no truncating open (grep), set_len only on the torn tail under the exclusive lock; prefix property test |
| T-04-05-02 | Tampering | Edited or foreign ledger line accepted | high | mitigate | Line::verify on every line, seq contiguity, version probe; Corrupt refuses the whole ledger |
| T-04-05-03 | Tampering | Torn write after a crash corrupting the next append | high | mitigate | Torn tail detected, reported as a count, truncated under the lock before the next write |
| T-04-05-04 | Tampering | Interleaved appends from two processes | high | mitigate | Exclusive File::lock per append, key set rebuilt under the lock; 4-thread test |

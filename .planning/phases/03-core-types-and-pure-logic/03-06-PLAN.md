<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| canonical Diff -> applier | The diff is model-originated; the applier must never interpret it more leniently than the validator |
| composed Diff -> ExperimentId, adopt, guest | The same bytes drive identity, the user's patch, and the candidate VM |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-03-06-02 | Elevation of privilege | Applier creating or deleting files | high | mitigate | No create or delete branch; path set preserved (property test) |

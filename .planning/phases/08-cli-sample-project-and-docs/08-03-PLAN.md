<objective>
Add the strict read-back of a snapshot tarball, so the CLI can build the run's base surface and program bytes from the packed bytes at `check`/`run` time and from the stored base blob at `report`/`show`/`adopt` time.

Purpose: No helper turns a snapshot or a stored base tarball back into a surface `Tree` (08-RESEARCH G3). `minos-source` owns the tarball format and only the CLI links it, so the reader lives here; it is the counterpart of `pack::tarball`.
Output: `read_files`, `ReadError`, `Snapshot::surface`, and tests.
</objective>

  <action>
1. New module `read.rs` (module docs: the read-back of the tarballs `snapshot` writes, used by the CLI for the base surface at `check` and `run` and from the stored base blob at `report`, `show`, and `adopt`; strict because a stored blob is still bytes from disk). `pub fn read_files(tarball: &[u8], paths: &BTreeSet<RelPath>) -> Result<Tree, ReadError>`: iterate `tar::Archive::new(tarball).entries()` in memory, reading each entry into a buffer and never extracting anything to disk; every entry must be `EntryType::Regular`, its path bytes must be UTF-8 and parse as `RelPath`, no path may repeat, at most `MAX_SNAPSHOT_FILES` entries, each at most `MAX_SNAPSHOT_FILE_BYTES` (checked from the header before reading, then read through `take(size + 1)` and compared), and the summed sizes at most `MAX_SNAPSHOT_BYTES`. Keep only the requested paths, in a `Tree`. Requested paths not seen are `ReadError::Missing { paths: Vec<RelPath> }` listing all of them, sorted. A tarball the `tar` crate cannot iterate, or that yields no end-of-archive, is `ReadError::Malformed { what: &'static str }` with fixed text ("not a ustar archive", "an entry is not a regular file", "an entry name is not a project path", "a path appears twice", "an entry is over its cap", "the archive is over its cap", "too many entries"). Use `BTreeSet`/`BTreeMap` for order.
2. `ReadError`: `#[non_exhaustive] #[derive(Debug, thiserror::Error)]` with `Missing { paths: Vec<RelPath> }` (message lists the paths) and `Malformed { what: &'static str }`; no variant carries file bytes.
3. lib.rs: `mod read;` then `pub use read::{ReadError, read_files};`; add a module-doc bullet. Add `impl Snapshot { pub fn surface(&self, manifest: &Manifest) -> Result<(Tree, Vec<u8>), ReadError> }` that calls `read_files` on `self.tarball` for `manifest.writable() ∪ manifest.readable() ∪ {manifest.program()}`, removes the program from the tree, and returns `(surface tree, program bytes)`. Doc: the tree is the run's base surface (`BaseTree::new(snap.tree(), tree)`), and the program bytes are `RunInputs.program`. Raise the walk caps to `pub(crate)` visibility only if they are not already reachable from `read.rs`; do not make them `pub`.
4. tests/read.rs: the behavior cases, with temp projects written like tests/pack.rs, `snapshot(.., CleanPolicy::AllowDirty, &BTreeSet::new())`, and hand-built malformed tarballs via `tar::Builder` and `tar::Header` (no shell). TestResult; no unwrap, expect, indexing, or allow.

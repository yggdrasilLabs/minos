<objective>
Make "a diff cumulative from the run's base" a type, so a parent-relative diff can never become an experiment ID by mistake, and move every caller onto it.

Purpose: 03-REVIEW WR-03 and D-12. The loop (07-10, 07-13) and the runner (07-12) build `Experiment`s and `JobRequest`s; with `CumulativeDiff` the only inputs are a diff minted against the base-tree handle or a diff re-read under its recorded ID. 07-03's clippy ban on `ExperimentId::of` in minos-loop closes the last path.
Output: `BaseTree`, `CumulativeDiff`, `cumulative`, `NotRecorded`, the retyped `compose` and `Experiment::candidate`, two compile-fail cases, and every caller in core tests, the guest, the krun backend, and minos-propose updated.

Scope note (27 files, kept as one plan on purpose): the signature change breaks every caller at once, so the workspace compiles only when all callers move together; each task stays within its budget because the caller edits are mechanical (a fixture builds `CumulativeDiff::recorded` from its own hash, a test builds a `BaseTree` from its tree).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model or sweep output -> experiment identity | A proposal's diff becomes the content address every later record keys on |
| blob store -> loop and runner | A diff re-read from its blob is trusted only if it hashes to its recorded experiment |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-06-01 | Tampering | A parent-relative diff recorded as an experiment (WR-03) | high | mitigate | `CumulativeDiff` has private fields and no conversion from `Diff`; `Experiment::candidate` takes only it; trybuild proves a parent `Tree` and a bare `Diff` are refused (D-12) |
| T-07-06-02 | Tampering | A re-read diff blob that does not match its experiment | medium | mitigate | `CumulativeDiff::recorded` refuses a diff whose hash under the base differs from the recorded `ExperimentId` |
| T-07-06-03 | Tampering | A parent cumulative from a different base composed into a new experiment | medium | mitigate | `compose` refuses with `ComposeError::BaseMismatch` |
| T-07-06-04 | Repudiation | Silent change of experiment IDs or wire bytes | high | mitigate | Hash bytes unchanged; the snapshots directories of core and propose are asserted unchanged; golden ID vectors untouched |
</threat_model>

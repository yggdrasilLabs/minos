<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| candidate VM -> runner | Hostile output stream; opened only through `Untrusted` exits here |
| runner -> judge VM | The judge receives judge data read-only through `secrets` and only the repacked `out/` files of the candidate |
| backend -> runner | `Ended` and `elapsed` are host observations and the only source of usage |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-12-01 | Information disclosure | Judge data reaching the candidate VM | high | mitigate | Only `SandboxSpec<Judge>::secrets` attaches it (trybuild-proven in Phase 4); preflight refuses judge data as input; a test asserts the Candidate plan has none (LOOP-02) |
| T-07-12-02 | Tampering | Candidate passes status, logs, or a forged scorecard to the judge | high | mitigate | `store_judge_input` keeps only `out/`; a test reads the judge input blob back and asserts the exact file set |
| T-07-12-03 | Spoofing | Candidate-reported timing becoming metered usage | high | mitigate | `host_usage` from `Finished::elapsed` only; a test plants forged timing files and asserts usage is unchanged (LOOP-03) |
| T-07-12-04 | Elevation of privilege | Objectives scored after a failed gate | high | mitigate | `judged_outcome` through `check_scorecard`; a test with a 0 gate and a missing objective expects `GateFailed` (JUDGE-03) |
| T-07-12-05 | Tampering | A request whose diff does not match its experiment launching a VM | medium | mitigate | `CumulativeDiff::recorded` before any launch; mismatch is `Config(DiffMismatch)` and nothing launches |
| T-07-12-06 | Denial of service (billing) | Retrying a deterministic configuration failure forever | medium | mitigate | `ScratchFull`, spec, preflight, and missing-blob faults are `Config` (never retried); only launch, wait, store I/O, and guest setup faults are `Infra` |
| T-07-12-07 | Elevation of privilege | Another crate opening `Untrusted` output | medium | mitigate | The LOOP-01 grep in this plan's verify and in 07-17's gate |
</threat_model>

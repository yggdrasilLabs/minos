<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| provider -> tier | A provider returns hostile model output or a typed error; the tier never trusts or repairs it |
| tier -> loop (Phase 7) | Only validated proposals, closed drop counts, usage, origin, and typed errors cross |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-05-01 | Tampering | single_shot (model edits outside the writable surface, or of the judge) | high | mitigate | Every item goes through `parse_output` (exact writable paths, `diff_trees` with the writable set); the manifest keeps judge paths out of `writable`; nothing is repaired |
| T-06-05-02 | Denial of service | A provider limit retried in a loop | high | mitigate | `ProposeError::stop_reason()` exposes `ProviderLimit`/`ProviderAuth` for the loop's `StopRequested`; the tier never retries; empty calls are `Ok` and count toward the empty-generation breaker, not the infrastructure streak |
| T-06-05-03 | Spoofing | A test double bypassing validation | medium | mitigate | `FakeProvider` replays raw JSON through `ModelOutput::from_value`; `Proposal::new` and the `Proposals` constructor are crate-private |
| T-06-05-04 | Repudiation | Proposals recorded without the prompt that produced them | medium | mitigate | `Origin::Model { model, prompt }` carries the exact prompt's `PromptHash`; the test checks it equals the hash of the recorded request's bytes |
| T-06-05-05 | Tampering | Sweep proposals diverging on replay | medium | mitigate | `sample` is seeded by run and generation (value-stable ChaCha8, pinned in core); the determinism test reruns one generation and compares bytes |
</threat_model>

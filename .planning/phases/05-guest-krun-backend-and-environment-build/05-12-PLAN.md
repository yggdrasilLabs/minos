  <action>
1. `main.rs`: dispatch by arguments and pid. If the first argument is `TRAMPOLINE_FLAG`, run the trampoline; else if the process id is 1, run PID 1; else print "minos-guest: runs only as /init inside a Linux VM" and exit failure. Non-Linux keeps today's stub.
2. `linux.rs` trampoline (D-08; 05-RESEARCH Pattern 5): refuse (exit 126, one stderr line) when the pid is 1 or the effective uid is 0; `parse_trampoline`; set `RLIMIT_AS`, `RLIMIT_FSIZE`, `RLIMIT_NPROC`, `RLIMIT_CPU`, `RLIMIT_NOFILE` to the parsed values and `RLIMIT_CORE` to 0, current and maximum equal; any failed `setrlimit` is fatal: write one stderr line naming the resource and exit 126 without exec, so no candidate code ever runs without its limits (this is the guest half of `ConfinementLayer::Rlimits`, which 05-07 and 05-11 record only when both halves are applied); then `Command::new(program).args(rest).exec()`; on return, write the error kind to stderr and exit 127. No pre-exec hook (std's is unsafe, and unsafe is forbidden).
3. `linux.rs` PID 1 (GUEST-01): boot work only: `console_line(BOOT_MARKER)`; mount `/proc` with data `hidepid=invisible` and NOSUID, NODEV, NOEXEC; mount `/sys` read-only with the same flags. Then per-run work: open `/dev/vdb`, read the input with `DiskJobSource`, close it, then remove the `/dev/vdb` node with `unlink` and, if removal fails, `chmod` it to mode 0, writing any failure as a console line (05-RESEARCH Pitfall 1 and A1: the token must be unreadable to every later process). Mount a tmpfs at `/scratch` with data `size=<scratch_mib>m,mode=0755` and NOSUID, NODEV (execution allowed: builds run programs there); `run_job` creates the subdirectories; bind-mount `/scratch/tmp` on `/tmp` and `/scratch/out` on `/out` after `run_job` creates them (do this through the `Handover` step or a prepare hook so the binds exist before the first stage). When the source fails before the token is known, write the setup-error marker line and power off.
4. `VsockConnector` implementing `Connector` with `VsockStream::connect_with_cid_port(VMADDR_CID_HOST, OUTPUT_VSOCK_PORT)` and close as `shutdown(Write)`; `ChunkSink::new(VsockConnector, token)` with `Backoff::standard()`.
5. `LinuxHandover`: recursive `lchown` (`chownat` with `AT_SYMLINK_NOFOLLOW`) of the directory tree to `GUEST_UID`/`GUEST_GID`, never following a link, plus the two bind mounts the first time it is called for `out` and `tmp`.
6. `LinuxExecutor` implementing `StageExecutor` (D-08; Pitfalls 7 and 12): spawn `trampoline_argv("/init", limits, argv)` with `uid(GUEST_UID)`, `gid(GUEST_GID)` (std drops supplementary groups when the parent is root), `env_clear()` then `STAGE_ENV`, `current_dir(cwd)`, `process_group(0)`, stdin null, and stdout and stderr both the write end of one `std::io::pipe()`; drain the read end on a thread into a buffer capped at `LOG_CAP_BYTES` plus one byte; poll `waitpid(Some(child), NOHANG)` every 10 ms against the deadline (never `wait` for any child while the stage runs); at the deadline record TimedOut. Then always `kill_process_group(Pid::INIT, Signal::KILL)` (kill(-1) reaches every process except PID 1, including those that left the group with setsid), reap with `wait` until ECHILD under a 5 s bound, join the drain thread, and map the status to `Exited { code }`, `Signaled { signal }`, `TimedOut`, or `SpawnFailed`.
7. After `run_job` returns: write `MINOS-GUEST-OUTPUT-SENT <connections>` or the sink error kind as one console line, `sync`, and power off. A PID 1 panic remains a kernel panic the host classifies as Crashed (P-PANIC); document it.

`crates/minos-guest/src/bin/minos-probe.rs`: a test fixture, documented as never packed into a user image (only the VM test harness puts it at `/usr/local/bin/minos-probe` in its own image). On non-Linux, `main` prints that it runs only inside a Linux VM and exits failure. On Linux, `minos-probe <command> <out file> [args]` runs one command and writes one JSON object to the out file (serde_json), exiting 0 when the probe itself ran:
- `egress <out> <ipv4 port> <ipv6 port> [host ip]`: TCP connect with a 3 s timeout to 127.0.0.1:<ipv4 port>, [::1]:<ipv6 port>, 1.1.1.1:443, 8.8.8.8:53, [2606:4700:4700::1111]:443, and the optional host IP on the ipv4 port; record per target `connected` (bool) and the raw OS error number; also list `/sys/class/net` names and every `/sys/bus/virtio/devices/*/device` id.
- `env <out>`: its own environment as key/value pairs, `/proc/cmdline` (capped at 64 KiB), real and effective uid and gid, supplementary groups, cwd, and `/proc/self/limits` lines for address space, file size, processes, CPU time, open files, and core file size.
- `write-outside <out>`: try to create a file in `/`, `/etc`, `/root`, `/usr`, `/scratch/judge`, and `/scratch/candidate`, and to open `/proc/1/environ` and `/dev/vdb` for reading; record the error number for each; also create files in `/tmp` and `/out` and record success.
- `forge <out>`: build a DATA chunk and an END chunk with an all-zero `ChunkToken` through `minos_core::chunk::ChunkStream`, send each over its own vsock connection to the host CID on `OUTPUT_VSOCK_PORT`, and record whether the connects succeeded.
- `hang`: sleep forever (no out file).
- `marker-write <path>` and `marker-check <path> <out>`: write a marker file; report whether the path exists.
- `output-fill <out-dir> <bytes>`: write `<bytes>` of the pattern into files of at most 8 MiB each under the directory.
- `alloc <out> <mib>`: try to allocate and touch that many MiB in 1 MiB steps; record how many succeeded and the error.
- `spawn <out> <count>`: start up to `count` sleeping children; record how many started before the process limit stopped it, then kill them.
- `fill-scratch <out>`: write a file under /scratch until the write fails; record bytes written and the error number.
- `scorecard`: write `{"v":1,"metrics":[{"name":"probe_ok","value":1,"held_out":false}]}` to `/out/scorecard.json` (used as a judge; it takes no path argument because a manifest refuses a judge argument that looks like a path outside the project, so the judge argv is the bare words `minos-probe scorecard`, found through STAGE_ENV's PATH).
- `exit <code>`: exit with the code.
Every command uses no unwrap, expect, or indexing; output JSON has fixed keys.
  </action>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PID 1 (root) -> candidate (uid 64000) | The privilege boundary inside the VM |
| candidate -> /dev, /proc, vsock | Candidate processes can reach kernel interfaces and the output port |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-12-01 | Spoofing | Candidate reading the per-launch token from /dev/vdb or PID 1's memory | high | mitigate | PID 1 reads the disk before any stage, then unlinks /dev/vdb (chmod 0 fallback); candidates run as uid 64000 and cannot ptrace root; /proc hidepid=invisible; exit_forge and write-outside assert it (05-17, 05-19) |
| T-05-12-02 | Tampering | Candidate processes racing the output packer | high | mitigate | kill(-1, SIGKILL) and reap until ECHILD before packing; the packer never follows links (05-10) |
| T-05-12-03 | Elevation of privilege | Candidate running as root or keeping supplementary groups | high | mitigate | Command::uid/gid as root drops groups; the trampoline refuses pid 1 and euid 0 |
| T-05-12-04 | Denial of service | Fork bombs, memory, CPU, file-size abuse | medium | mitigate | Trampoline sets NPROC, AS, CPU, FSIZE, NOFILE, CORE before exec and exits 126 without exec if any setrlimit fails; PID 1's stage deadline; kill-all after every stage |
| T-05-12-05 | Information disclosure | Host values in the candidate environment | medium | mitigate | env_clear then STAGE_ENV; exit_env asserts env and /proc/cmdline (05-19) |
| T-05-12-06 | Tampering | Writes outside scratch | medium | mitigate | Read-only SquashFS root; tmpfs /scratch with /tmp and /out bound from it; write-outside probe asserts failures (05-17) |
| T-05-12-07 | Repudiation | A probe binary shipped in user images | low | mitigate | env build packs only the minos-guest binary as /init (05-16); the probe is documented as a fixture and placed only by the VM harness |
</threat_model>

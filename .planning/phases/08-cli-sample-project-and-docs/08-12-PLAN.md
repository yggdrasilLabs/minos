| binary -> claude CLI | The provider preflight inspects the parent environment |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-12-01 | Spoofing | Credential variables in the parent environment reaching the model call | high | mitigate | `ParentEnv::from_vars` and `ClaudeCli::preflight` refuse them by name (06-CONTEXT D-03); `run` cannot start without a passing preflight |
| T-08-12-02 | Tampering | Malformed run, experiment, or hash arguments | medium | mitigate | clap value parsers through `HexPrefix::from_str` and `ReportHash::from_str`; `--generations` at least 1; tested |
| T-08-12-03 | Tampering | Terminal injection through error chains | medium | mitigate | `main` prints every error through `SafeText` (existing); warnings too |
| T-08-12-04 | Elevation of privilege | Launching on an unprobed host | high | mitigate | `check` and `run` compose only through `krun_jobs`, which refuses a host with failed probes |
| T-08-12-05 | Repudiation (cost) | Help text promising an estimate | low | mitigate | The help-text banned-word test |
</threat_model>

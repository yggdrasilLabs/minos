## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| rationale blobs, diff text, literals -> report text -> terminal | Model- and sandbox-originated strings reach the reviewer |
| report bytes -> ReportHash -> adopt | The acknowledgement must bind to exactly what was shown |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-12-01 | Spoofing / Tampering | Escape or bidi injection hiding content from the reviewer | high | mitigate | Every hostile string through SafeText; hidden-characters flag; inert-rendering test |
| T-03-12-02 | Repudiation | Acknowledged hash not matching what was shown | high | mitigate | ReportHash::of over the rendered bytes; fixed section order; byte pin on golden reports |
| T-03-12-03 | Tampering | Order-dependent report bytes | medium | mitigate | Sorted sets everywhere; report_is_order_insensitive property over shuffled ledgers |
| T-03-12-04 | Information disclosure | Judge data leaking into the report | high | mitigate | Judge data is not an input to build_report (signature and grep check) |

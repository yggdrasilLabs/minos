<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `minos.toml` -> Manifest | The user's manifest; `trials` is range-checked like every budget |
| `minos.lock` -> Lock | A committed, possibly edited file; parsed with `deny_unknown_fields`, `try_from`, and a size cap before parsing |
| `prices.toml` -> Prices | User config; completeness is checked against the manifest before a run |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-02-01 | Tampering | Hand-edited `[[judge]]` table (reordered, duplicated, or extra keys) | medium | mitigate | `deny_unknown_fields` on both raw tables, strict ascending path order, count equality, duplicate-label refusal; one wire form per lock |
| T-07-02-02 | Denial of service | Oversized lock text | low | mitigate | `parse_toml` refuses text over `MAX_LOCK_BYTES` before parsing; the raised cap is const-asserted against `MAX_JUDGE_FILES` |
| T-07-02-03 | Information disclosure | Judge file paths and low-entropy digests in a committed lock | medium | accept | D-02 as amended: the lock holds paths and digests, never data; the docs state that paths are exposed and low-entropy digests are guessable (07-11 writes the CLAUDE.md wording) |
| T-07-02-04 | Denial of service (billing) | A run priced at zero through a missing model rate | high | mitigate | `missing_models` lets the loop refuse before any call (D-13); the post-call re-check for resolved IDs lands in 07-15 |
| T-07-02-05 | Tampering | `trials` changing the judge identity | low | mitigate | `trials` is excluded from `JudgeVersion`'s canonical spec; the golden vector is asserted unchanged |
</threat_model>

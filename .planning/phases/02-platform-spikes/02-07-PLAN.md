### E-1: orphan_launcher

`orphan_launcher` is an ignored test. When `MINOS_SPIKE_ORPHAN_CONFIG` is unset it returns `Ok(())` immediately, so a plain `--ignored` run does nothing with it. When set, it reads `MINOS_VMM`, `MINOS_SPIKE_ORPHAN_CONFIG` (the `vmm.json` path), and `MINOS_SPIKE_ORPHAN_DIR` (the job directory); spawns `[MINOS_VMM, config]` with `env_clear()`, null stdin, stdout to `<dir>/vmm.stdout`, stderr to `<dir>/vmm.stderr`, and `process_group(0)`; writes the child's PID to `<dir>/vmm.pid`; and returns without waiting.

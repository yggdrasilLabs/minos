<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI -> VMs and model | `run` drives candidate and judge VMs and, through the proposer, model calls |
| ledger -> terminal | Every progress line is built from the fold and printed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-08-01 | Tampering | Terminal injection through progress lines | medium | mitigate | Lines carry IDs, numbers, and closed-enum names only, and still pass `render::write_line` (`SafeText`); the golden asserts each line is `SafeText`-stable |
| T-08-08-02 | Spoofing | A "new" run silently rejoining an existing one | medium | mitigate | `RunExists` refusal before `Driver::start`; tested |
| T-08-08-03 | Tampering | Resuming under a changed base, image, judge, or frame | high | mitigate | `Driver::resume`'s checks stay in force; `run` surfaces them as `ResumeRefused` naming a new run; tested |
| T-08-08-04 | Repudiation (cost) | Cost shown without measurement or tokens | low | mitigate | Only `CostLine` from `run_cost`; banned-word helper on all outputs |
| T-08-08-05 | Denial of service | A stop that never takes effect | medium | mitigate | `run` honors the driver's session-relative stops; tested with a mid-trial `UserStop` |
</threat_model>

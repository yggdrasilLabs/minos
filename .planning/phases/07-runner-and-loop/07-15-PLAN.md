2. `enum SafePoint { Generation, ModelCall, Launch, AfterTrial }` (private) and `fn safe_point(&mut self, at: SafePoint, generation: u32) -> Result<Option<RunEnd>, DriverError>`: refold; any stop in `state.stops()` not in `session_stops` ends the session with `RunEnd::Stopped` and records nothing (D-19); at `Generation`, `circuit_breaker(&state, manifest.budget(), self.streak)` returning a reason appends `StopRequested { generation, reason }` (a duplicate key is fine) and ends; at `Generation`, `ModelCall`, and `AfterTrial`, `spend_ok`: `Stop(reason)` appends and ends, `Err(CostError::UnpricedModel { model })` is `DriverError::UnpricedModel { model }`, any other `CostError` is `DriverError::Cost`; at `Launch`, only new stops. Emit `LoopEvent::Stopped` whenever the session ends here; during generation 0, `calibrate` returns `Calibrated::Stopped { reason }`. Insert the calls: before each step of `run_to` (`Generation`, with `generation` = last concluded + 1), before each `propose` call (`ModelCall`), before each `jobs.run` in both calibration and trials (`Launch`), and after each trial's records (`AfterTrial`). After every model call, success or error with usage, run the `ModelCall` spend check again before admitting, so an unpriced resolved model stops the run right after its first paid call (D-13 extended).
3. Retries (D-16): a private `fn retry(&mut self, generation: u32, what: &'static str) -> Result<Option<RunEnd>, DriverError>` that increments `streak`, emits `LoopEvent::Retrying { streak, max }`, and when `streak >= manifest.budget().max_infra_failures()` appends `StopRequested { generation, InfraFailures }` and returns `RunEnd::Stopped`; otherwise sleeps `options.retry_pause` with `std::thread::sleep` and returns `None` so the caller re-derives the same step. Use it for `JobFailure::Infra` (the same `LaunchKey` is re-derived from the fold), a provider error with `is_infra()` (the next call index comes from the fold), and in `record::append` call sites through a wrapper that retries only the append while holding the result already obtained (a `DriverError::Store` whose source `is_retryable`). Reset `streak` to 0 after every successful job, propose call, and append. A failed attempt records nothing. Document the pause constant's reason beside `RETRY_PAUSE`.

Backend pin (D-11, JUDGE-04): right after `jobs.run` returns and before any append for that trial (baseline or candidate), refuse a result whose `(backend.backend(), backend.arch())` is not the single element of `state.backend_classes()` (an empty set accepts it) with `DriverError::BackendChanged { recorded, found }`.
5. Module docs: the safe-point table, session-relative stops, metered-only caps with the one-step overshoot (D-15), the retry streak and pause, and that the driver never kills a running VM (a stop takes effect at the next safe point after the running trial is recorded).

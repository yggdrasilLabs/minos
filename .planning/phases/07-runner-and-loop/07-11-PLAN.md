<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user's judge directory -> `.minos/blobs` and `minos.lock` | Private data enters the store; only digests and paths enter the committed lock |
| `minos.lock` (possibly edited) -> later runs | A label maps to a tree digest the runner trusts as judge data |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-11-01 | Tampering | Silently replacing a label's judge data mid-project | high | mitigate | Different data under an existing label is refused without `--update`, naming both digests; the lock is unchanged on refusal (D-01) |
| T-07-11-02 | Information disclosure | Judge data placed where the snapshot or image context picks it up | high | mitigate | A judge directory inside the project must lie under a `[source] exclude` entry; 07-08's overlap refusal catches copied files (JUDGE-01, D-04) |
| T-07-11-03 | Information disclosure | Secrets or credentials pushed as judge data | high | mitigate | `pack_judge_data` runs the denylist and the secret scan with no override; drops are listed (D-03) |
| T-07-11-04 | Tampering | A partially written lock | medium | mitigate | `write_lock` writes a synced temporary file in `.minos`, persists it over the lock, and syncs the directory; blob first, lock last |
| T-07-11-05 | Denial of service | Every judge VM failing on a missing judge program | low | mitigate | A push lacking a judge argv path is refused naming it (A9) |
| T-07-11-06 | Information disclosure | Hostile or odd file names printed to a terminal | low | mitigate | Every printed path goes through `SafeText` |
</threat_model>

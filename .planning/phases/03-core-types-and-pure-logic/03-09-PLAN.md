## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| loop -> runner JobRequest | Trusted code on both sides, but the diff blob it names is model-originated |
| on-disk ledger -> Record | Persisted bytes must parse identically forever |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-09-01 | Tampering | Runner applying a diff that is not the experiment's | high | mitigate | JobRequest::verify_diff recomputes ExperimentId::of(base, diff); DiffMismatch on parse for baseline/diff inconsistency |
| T-03-09-02 | Tampering | Silent wire-format drift | high | mitigate | insta snapshot per format plus a SHA-256 byte pin over all golden bytes; INSTA update: no |
| T-03-09-03 | Tampering | Old lines becoming unparseable or new lines accepted by old readers | medium | mitigate | Round-trip and rejection tests for v tag, unknown variant, unknown field, missing field |
| T-03-09-04 | Repudiation | Dollar amounts entering the ledger | medium | mitigate | spent_carries_no_dollar_field |
| T-03-09-05 | Tampering | Metric bits changing through the internally tagged Record | high | mitigate | metric_bits_survive_record_round_trip property |
</threat_model>

Also a constructor for tests and the runner: `Scorecard::from_entries(entries: impl IntoIterator<Item = (MetricName, Metric, bool)>) -> Result<Scorecard, ScorecardError>` that goes through the same validation.

Document the module: this is the only way sandbox scorecard bytes become a Scorecard (Phase 4's `Untrusted::into_scorecard` calls it).

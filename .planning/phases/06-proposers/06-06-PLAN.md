`src/claude_cli/process.rs`, crate-private (declare `mod process;` in `claude_cli/mod.rs`), per D-16 and Pattern 3:
1. `pub(crate) struct RunSpec<'a>` with crate-visible fields `program: &'a Path`, `args: &'a [OsString]`, `env: &'a [(OsString, OsString)]`, `cwd: &'a Path`, `stdin: &'a [u8]`, `deadline: Duration`, `stdout_cap: u64`, `stderr_cap: u64`. `pub(crate) struct RunOutput { exit: Exit, stdout: Vec<u8>, stderr_tail: Vec<u8> }`. `pub(crate) enum RunError { Spawn, Wait, Deadline, StdoutTooLarge }` (unit variants: the OS error is not surfaced, because every provider error is a closed cause, and a crate-private payload that is never read would fail the dead-code lint) with `pub(crate) fn cause(&self) -> InfraCause` (Spawn, Wait, Deadline, OutputTooLarge).
2. `pub(crate) fn run(spec: &RunSpec<'_>) -> Result<RunOutput, RunError>`: build the `Command` with `args`, `env_clear`, `envs`, `current_dir`, piped stdin, stdout, and stderr, and `process_group(0)`; spawn. Inside `std::thread::scope`: a writer thread writes `stdin` and drops the pipe (a write error, `BrokenPipe` included, is ignored: the child may exit without reading); a stdout reader reads through `take(cap + 1)`, and on exceeding the cap sets an `AtomicBool` and drains the rest to a sink; a stderr reader keeps the last `stderr_cap` bytes it sees (a bounded ring or a truncate-from-front buffer) and drains the rest. The scope body polls every `POLL_INTERVAL` with `waitid(WaitId::Pid(pid), WaitIdOptions::EXITED | WaitIdOptions::NOHANG | WaitIdOptions::NOWAIT)` until the leader has exited, the overflow flag is set, or the deadline passes; then, in every case and before any reader is joined, `kill_process_group(pid, Signal::KILL)` (ignore `ESRCH` and `EPERM`), `child.kill()` ignored, and `child.wait()` to reap (an error is `Wait`). Leaving the scope joins the threads, which now reach EOF. The result is `Deadline` if the deadline fired before the leader exited, `StdoutTooLarge` if the flag is set, else `RunOutput` with `Exit::Code` or `Exit::Signal` from the status (`ExitStatusExt::signal`). Thread joins never unwrap.
3. Unit tests in a `#[cfg(test)] mod tests` block of process.rs (the runner is crate-private), one per behavior row, returning `Result` and using `tempfile` directories; the shell commands are fixed test text, never built from input.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| minos -> claude subprocess | Minos launches the user's binary; the process tree is bounded by deadline, caps, and group kill |
| claude stdout/stderr -> minos | CLI output (version, auth status, errors) is untrusted text; it is parsed narrowly and shown only through `SafeText` |
| parent environment and HOME -> preflight | Variables, `~/.local/bin/claude`, `$TMPDIR` ancestors, and `~/.claude/settings.json` (seen only through `auth status`) decide whether the run may start |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-06-01 | Denial of service | Hung `claude`, or a grandchild holding a pipe | high | mitigate | `process::run` polls with `waitid(WNOWAIT)`, kills the whole process group at the deadline or as soon as the leader exits, reaps, and only then joins readers; tests prove the grandchild is gone and no hang |
| T-06-06-02 | Denial of service | Unbounded stdout or stderr | medium | mitigate | stdout read through cap + 1 with an early group kill on overflow; stderr keeps a capped tail and drains the rest; tests with `/usr/bin/yes` and a 1 MB stderr |
| T-06-06-03 | Spoofing | API key or token taking over the subscription login, including through `~/.claude/settings.json` | high | mitigate | Parent credential-name scan refuses before anything runs; `auth status` must report `claude.ai`, `firstParty`, and no `apiKeySource`, which is the one check that sees settings-level key helpers and providers |
| T-06-06-04 | Information disclosure | `auth status` PII (email, organization) and credential values | medium | mitigate | The auth struct declares only four fields, so PII is never bound; values of refused variables are never stored; `Preflighted`'s Debug prints version and path only; tests assert the strings are absent |
| T-06-06-05 | Elevation of privilege | Project configuration (CLAUDE.md, `.mcp.json`, `.claude/`, a repository) above the working directory | high | mitigate | The work root's ancestors are checked and refused when they hold project markers; every run gets a fresh 0700 `tempfile` directory under it, removed afterwards |
| T-06-06-06 | Tampering | An old or mismatched binary running under a proven-contract assumption | medium | mitigate | `--version` must parse, equal the file name's version, and be at least 2.1.296 |
</threat_model>

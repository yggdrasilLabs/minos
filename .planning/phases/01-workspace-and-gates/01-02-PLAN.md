<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Package sources (crates.io, git hosts, alternative registries) to Cargo.lock | Any dependency source other than crates.io at an exact version is untrusted |
| Dependency build scripts to the developer machine | A build.rs runs arbitrary code at build time, before any Minos code |
| Crate graph edges to architectural isolation | An edge from minos-core or minos-loop to sandbox or backend code would let raw sandbox output reach code that must never see it |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1-07 | Tampering | Git dependency on a moving branch or tag | high | mitigate | `required-git-spec = "rev"`, `unknown-git = "deny"`, `allow-git = []`; Plan 01-03 proofs V-11 and V-12 |
| T-1-08 | Spoofing | Alternative registry or mirror injection | high | mitigate | `unknown-registry = "deny"`; Plan 01-03 proof V-13 |
| T-1-09 | Elevation of Privilege | Unreviewed build.rs or shipped executable | high | mitigate | `[bans.build] allow-build-scripts` naming 25 reviewed crates, `executables = "deny"`; an unlisted build script is a stop-and-report, never an automatic allowlist entry; Plan 01-03 proof V-14 |
| T-1-10 | Tampering | C, OpenSSL, or libgit2 code entering the graph | high | mitigate | Ban entries for openssl-sys, openssl, native-tls, git2, libgit2-sys, gix, zstd-sys, liblzma-sys, cc; `all-features = false` so the checked graph matches the build; Plan 01-03 proof V-23 |
| T-1-11 | Elevation of Privilege | A forbidden crate edge (core or loop to sandbox, a backend, or the runner), anyhow in a library, msb_krun outside minos-vmm | high | mitigate | One `deny` entry with `wrappers` per internal library crate (wrappers cover direct edges only, so each crate needs its own entry), plus anyhow to minos-cli and msb_krun to minos-vmm; dev-dependency edges are in the checked graph; Plan 01-03 proofs V-15 to V-22 |
| T-1-12 | Tampering | A member redeclaring a dependency outside the exact workspace pins, or a wildcard version | medium | mitigate | `[bans.workspace-dependencies]` duplicates and unused at deny with path dependencies included; `wildcards = "deny"`; internal path dependencies carry `=0.1.0` |
| T-1-13 | Tampering | A known-vulnerable, unmaintained (direct), or yanked crate | medium | mitigate | RustSec advisories fail by default, `unmaintained = "workspace"`, `yanked = "deny"`; an advisory hit is a stop-and-report, never an `ignore` entry |
| T-1-14 | Denial of Service | `cargo deny check` needs the network to refresh the advisory database | low | accept | `cargo deny --offline check` uses the cached database; this does not weaken any check |
| T-1-SC | Tampering | Supply chain for every later dependency change | high | mitigate | From this plan on, every dependency change passes T-1-07 to T-1-13 before it can land; the first-build exposure before this file existed is covered in Plan 01-01 |

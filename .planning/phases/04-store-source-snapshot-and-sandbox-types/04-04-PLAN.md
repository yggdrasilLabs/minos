<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user working tree -> snapshot | Everything packed leaves the user's control and enters a VM; secrets and judge files must not |
| minos -> git subprocess | git reads repository config; configured programs must not run, and output is untrusted in size |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-04-01 | Information disclosure | Credentials or keys packed into the snapshot | high | mitigate | Fixed denylist (.ssh, .aws, .env*, *.pem, id_*), case-insensitive; nine-pattern scan with no override; a hit never echoes bytes |
| T-04-04-02 | Tampering | Judge program reaching the candidate tree | high | mitigate | JudgePath deny rule independent of [source] exclude (applied by the walk in 04-07) |
| T-04-04-03 | Elevation of privilege | git running a configured program (fsmonitor) during status | high | mitigate | -c core.fsmonitor=false and core.hooksPath=/dev/null; no HOME, no system or global config; argv only, no shell |
| T-04-04-04 | Denial of service | Catastrophic regex backtracking on a hostile file | medium | mitigate | regex crate is linear-time; RegexSet single pass |
| T-04-04-05 | Denial of service | git hanging or flooding a pipe | medium | mitigate | 30 s deadline with kill and reap; capped stdout and stderr read on scoped threads |
| T-04-04-06 | Spoofing | A packed file that git status cannot see (info/exclude, global excludes) making a dirty snapshot look clean | medium | mitigate | ls-files subset check: every packed path must be tracked |
| T-04-04-07 | Information disclosure | Secret-shaped test vectors committed to the repository | medium | mitigate | Vectors joined at run time; self-scan test over minos-source's own sources |
| T-04-04-08 | Spoofing | Terminal escapes in git stderr shown to the user | low | mitigate | stderr is drained, never displayed |
</threat_model>

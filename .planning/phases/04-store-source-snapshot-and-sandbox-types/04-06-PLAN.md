2. `crates/minos-sandbox/src/output.rs` (SBX-05). Caps from the interfaces block as `pub const`s with reasons. `#[non_exhaustive] pub enum OutputCap { Stream, Entries, Entry, Total, DiffCount, DiffBytes }`, `#[non_exhaustive] pub enum OutputInvalid { NotBlockAligned, NotUstar, EntryType, Path, Truncated, Duplicate, NoEndMarker, TrailingData, Malformed, DiffNotText }` (both Clone, Copy, Debug, PartialEq, Eq), and `#[non_exhaustive] pub enum OutputFault { TooLarge { cap: OutputCap }, Invalid { why: OutputInvalid } }` (Debug, Clone, Copy, PartialEq, Eq, thiserror::Error; messages name the cap or the rule, never input bytes) with `pub const fn reason(&self) -> Reason`. Module doc: the step order below, why raw mode (our guest writes plain ustar, so refusing every extension type is simpler and stronger than processing it, and the PAX-desync class cannot occur), and the allocation-bound argument (the slice is refused above its cap before parsing; raw mode never buffers an extension record; each entry is read through `take(size)` after the per-entry cap with at most 64 KiB preallocated; no global allocator can measure it because unsafe code is forbidden; RESEARCH Pitfall 9).
   `pub(crate) fn read_output<R: Role>(stream: &[u8]) -> Result<Untrusted<GuestOutput<R>>, OutputFault>`:
   a. Length over MAX_OUTPUT_STREAM_BYTES: TooLarge Stream. Length not a multiple of 512: Invalid NotBlockAligned.
   b. `tar::Archive::new(std::io::Cursor::new(stream))`, `entries()` then `.raw(true)`. An io error of kind UnexpectedEof is Invalid Truncated; any other io error from the tar crate is Invalid Malformed (the input is in memory, so nothing here is infrastructure).
   c. Per entry, in this order and before reading any data: count over MAX_OUTPUT_ENTRIES (TooLarge Entries); `as_ustar()` is None (Invalid NotUstar); `as_old().linkflag != [b'0']` (Invalid EntryType); `size()` over MAX_OUTPUT_ENTRY_BYTES (TooLarge Entry); `path_bytes()` through `std::str::from_utf8` then `RelPath::try_from` (Invalid Path; the D-01 grammar, so `..`, absolute, empty, backslash, NUL, and non-ASCII names are refused); running total with `checked_add` over MAX_OUTPUT_CONTENT_BYTES (TooLarge Total); a name already in the map (Invalid Duplicate). Then read through `take(size)` into a Vec preallocated with at most 64 KiB; fewer than `size` bytes is Invalid Truncated. Record `end = raw_file_position() + size rounded up to 512` with checked arithmetic.
   d. After the iterator ends: the bytes from `end` (0 for no entries) to the end of the slice must be at least 1024 long (else Invalid NoEndMarker) and all zero (else Invalid TrailingData). Use `.get(..)`; no indexing.
   Nothing here touches the filesystem.

<objective>
Build the shared CLI library every Phase 8 command composes: preparing a project for a run, opening the store for read-only commands, naming runs and experiments by prefix, the shared output helpers, the krun composition, and the module files the command plans fill.

Purpose: `check` and `run` share one preparation path whose refusals name the next command (D-06); every run-taking command resolves prefixes the same way (D-10); every printed line passes the same renderer (D-14 to D-17). Declaring all command modules here lets five command plans run in parallel in wave 3 with no shared file.
Output: `project.rs`, `address.rs`, `render.rs`, `jobs::krun_jobs`, the corrected `env build` help, nine command module files, and two test targets.

Scope note (checker review, 2026-10-28): `files_modified` lists 17 files, but nine of them (`check.rs` to `init.rs`) are new files holding only a module doc comment, a few lines each, so the plans that fill them in wave 3 own no shared file. The plan is not split, because every new module must be declared in `lib.rs`: two wave-2 plans would both edit `lib.rs`, and running them in sequence instead would push the five wave-3 command plans and every later plan back one wave.

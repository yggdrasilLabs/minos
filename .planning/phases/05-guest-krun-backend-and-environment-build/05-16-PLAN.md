<objective>
Implement `minos env build`: the project's Dockerfile becomes a raw read-only SquashFS root image with `/init` written in by the trusted packer, stored as a blob, with `minos.lock` recording its digest and inputs, refusing a changed digest unless `--update`.

Purpose: KRUN-09 and CLI-02, with D-09 (streaming put into `.minos/blobs`; the blob ID is the image digest), D-10 (`--update` gate), D-11 (lock contents), and D-12 (reproducibility claimed for the image, not the builder's tar). The Docker daemon is not running on this host, so every test that needs Docker is ignored and run in 05-18; everything else is tested with a fake builder.
Output: builder.rs, env_build.rs, the `env build` subcommand, and tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| working tree -> build context | The user's files become the builder's context |
| user Dockerfile -> builder -> packer | The builder's tar is hostile input to the trusted packer |
| minos.lock on disk | Gates which image a run may use |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-16-01 | Information disclosure | Judge data or secrets baked into the root image | high | mitigate | The context is exactly the snapshot tarball (judge paths excluded, denylist, secret scan, clean check); tested with a fake builder that records its context |
| T-05-16-02 | Tampering | A Dockerfile replacing /init | high | mitigate | The packer writes the verified static guest last as /init (RI-03, 02 D-18); check_guest_elf before packing |
| T-05-16-03 | Tampering | Hostile rootfs tar from the builder | high | mitigate | pack_root_image's caps and path rules (Phase 2), never unpacked on the host |
| T-05-16-04 | Repudiation | A changed image silently replacing the locked one | medium | mitigate | LockMismatch without --update, printing both digests; atomic lock rewrite with --update (D-10) |
| T-05-16-05 | Spoofing | Builder subprocess inheriting the user's environment (proxies, credentials, DOCKER_* overrides) | medium | mitigate | env_clear then HOME and a fixed PATH only; argv array |
| T-05-16-06 | Tampering | Base image by tag instead of digest | medium | mitigate | base_images refuses a tag or a missing digest; digests recorded in the lock |
| T-05-16-07 | Denial of service | Unbounded build time or output | low | mitigate | 30-minute builder deadline; the packer's 1 GiB tar cap; put_reader cap |
</threat_model>

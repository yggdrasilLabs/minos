CLI-02's `minos.lock` records what D-11 lists, with the check and replace operations D-10 and D-11 need.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| guest processes -> host output socket | Any guest process can connect to the output vsock port; only PID 1 holds the token |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-02-01 | Spoofing | Candidate forging an output stream on the vsock port (05-RESEARCH Pitfall 1) | high | mitigate | Every chunk carries the 32-byte per-launch token; Reassembler refuses a wrong token with ChunkFault::Token (Reason::ChunkProtocol), compared in constant time; the token never appears in Debug output |
| T-05-02-02 | Tampering | Gaps, duplicates, oversize or mis-sized chunks, a second END, a forged END | high | mitigate | Each is a distinct ChunkFault mapped to Reason::ChunkProtocol; the END digest binds the whole payload |
| T-05-02-03 | Denial of service | Connection or byte flooding of the receiver | medium | mitigate | max_total cap and max_connections = ceil(max_total/4096)+1 enforced before buffering; poisoned after the first fault |
| T-05-02-04 | Repudiation | A guest that died mid-send blamed as a protocol violation | medium | mitigate | NoEnd is is_incomplete(), letting the host classify it as Crashed rather than ChunkProtocol |
| T-05-02-05 | Tampering | A hand-edited minos.lock with unknown keys or duplicate entries | medium | mitigate | deny_unknown_fields on every raw table, try_from refuses duplicates and non-canonical base_images, a byte cap before parsing, golden snapshot plus SHA-256 pin |

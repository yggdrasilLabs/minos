<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Docker build output (rootfs tar) to the packer | The tar is built from a user Dockerfile and is hostile: names, types, sizes, and links are attacker-chosen |
| Packer output (image) to the VM | The image is read-only to the guest; nothing in it is ever unpacked or mounted on the host |
| Docker daemon and registry | Base image pulled by digest; the build context holds only the Dockerfile |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-22 | Tampering | rootfs tar path traversal or absolute names | high | mitigate | In-memory parse only; component-wise normalization rejects parent-dir, root-dir, prefix, NUL, non-UTF-8; unit tests for each; tar unpack methods banned by clippy (D-PROBE-BK) |
| T-02-23 | Elevation of Privilege | device nodes or FIFOs in the image | medium | mitigate | Every entry type outside file, directory, symlink, hardlink is rejected; unit test with a character device |
| T-02-24 | Denial of Service | oversized tar, entry, or entry count | medium | mitigate | `take(max_tar_bytes + 1)` with overflow detection; header size checked before reading; entry count cap; unit tests for each |
| T-02-25 | Tampering | a Dockerfile supplying its own /init | high | mitigate | /init removed and re-inserted last from the trusted guest bytes; `init_overridden` reported; unit test |
| T-02-26 | Tampering | non-deterministic image bytes hiding changes | low | mitigate | mtime 0, BTreeMap order, clock setter banned; same-input test and frozen golden vector |
| T-02-27 | Tampering | base image substitution | medium | mitigate | FROM pinned by index digest; RI-01 records the resolution |
| T-02-28 | Information Disclosure | secrets in the build context | low | mitigate | The fixture context is a directory holding only the Dockerfile |
| T-02-SC | Tampering | package installs | low | accept | No new crate; no container engine installed or started |

### E-3: newc layout (initramfs.rs)

|---|---|---|---|---|---|---|---|---|---|---|---|
| init | 1 | 000081ED (0100755) | 0 | 0 | 1 | 0 | len(init) | 0 | 5 | 0 | `init` |
| trailer | 0 | 0 | 0 | 0 | 1 | 0 | 0 | 0 | 11 | 0 | `TRAILER!!!` |
